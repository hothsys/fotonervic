Status Guide

EXIF Only File has metadata/EXIF but zero recoverable image data. The camera framing data survived but the photo itself did not.
Partial / Truncated Image began writing but was cut off. May partially display or throw a decode error.
Corrupt File header or data structure is invalid. Unlikely to be recoverable without specialist tools.
Empty 0-byte file or too small to contain any image. Filename survived, contents did not.
Error Could not be checked (permissions, I/O error, unsupported variant). Inspect manually.
